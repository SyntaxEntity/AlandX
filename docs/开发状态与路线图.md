## 三、明确没做

- **推送**：接口没有，只能前台轮询 `/feed?uuid=`，未实现
- **图片磁盘缓存**：只缓存 JSON，图片每次重进都重下
- **楼层定位**：点 `>>No.` 打开的是整串，不会滚到对应楼层
- **深色模式**：`buildTheme` 硬编码 `Brightness.light`，`MaterialApp` 没给 `darkTheme`
- **请求重试与退避**：一次失败即报错，没有指数退避
- **单元测试**：`test/` 目录被删（`flutter create` 生成的模板测试引用不存在的 `MyApp`），目前零测试

## 四、和 FlClash 的对应关系

底栏是照 FlClash 的 `NavigationDock` 交互写的，但**没有复制它的源码**，原因有两个：

1. **许可证**。FlClash 以 **GPL-3.0** 分发。把它的代码搬进本项目，本项目就必须整体改为 GPL-3.0
   并附带源码提供义务。当前项目是"仅供学习交流"的模糊状态，不应被动继承 GPL。
2. 取源码的过程也不顺：`github.com` 被墙，`jsdelivr` 对部分文件 404/503，`codeload` 源码包
   下载到 7.4 MB 时被限速截断。最终只读到 `lib/pages/home.dart` 这一层的调用契约。

所以实现方式是**按观察到的行为契约重写**：

| 维度 | FlClash | 本项目 |
|---|---|---|
| 悬浮与否 | 悬浮，`NavigationDock.insetOf` 给内容让位 | 一致 |
| 选中项形态 | 横向展开露出文字 | 一致 |
| 切换手势 | 底栏上横向滑动 | 一致 |
| 位置模型 | `PageController` + `PageView`，`NeverScrollableScrollPhysics` | 单个 `_pos` 浮点位置 + `AnimationController` 吸附 |
| 标签显隐 | 未确认 | `ClipRect + Align(widthFactor)` 横向拉出 |
| 宽度动画 | 未确认 | 相邻两项权重和恒为 1，总宽不变 |
| 触觉反馈 | 未确认 | 跨格 `HapticFeedback.selectionClick()` |

差异点集中在上表后三行——那是原实现的内部做法，无法从外部观察，属于自行设计。

## 五、开发计划

### P0 · 让"能否跑通"有答案（阻塞中）

1. 等站点恢复，或找到可用镜像，跑一次真实读链路
2. **修 `api.dart` 写接口路径大小写**：现在是 `/home/forum/doPostThread.html`，
   X岛网页端实际是 `/Home/Forum/doPostThread.html`，Linux 下 PATH_INFO 大小写敏感，
   很可能直接 404。这是当前最高风险项。
3. 真机装包验证：启动、滚动手感、底栏滑动切换

### P1 · 去网页感

现状被评价为"看起来像网页"，主要来自三处：

1. **配色写死**。`widgets.dart` 里 `kInk/kInk2/kOutline` 和大量 `Colors.white` 绕过了
   `ColorScheme`，导致主题色切换只在局部生效。需要统一收口到 `Theme.of(context)`。
2. **没有深色模式**。补 `darkTheme` + `themeMode: system`，同时干掉写死颜色，
   否则深色下会出现白底白字。
3. **卡片层级扁平**。当前 `SurfaceCard` 是"白底 + 1px 描边 + 大圆角"，这是典型的网页卡片语言；
   原生 Material 3 用 surface 色阶 + elevation 表达层级。改为 `Material 3` 的
   `surfaceContainer*` 阶梯，去掉描边。

### P2 · 补功能

1. 楼层定位（`Scrollable.ensureVisible` + GlobalKey 映射楼层）
2. 图片磁盘缓存（`cached_network_image` 或自建 LRU）
3. 订阅更新轮询（前台 60s 拉 `/feed?uuid=`，与已读状态对比）
4. 发串草稿（本地暂存，防误退）

### P3 · 工程质量

1. 引入 `flutter_lints` 并清理告警（当前 `analysis_options.yaml` 特意关掉了，避免 CI 红）
2. 给 `api.dart` 的解析逻辑补单元测试（`_parseJump` / `_parseSearch` 这种靠文案猜的代码最需要）
3. Release 签名（当前是 debug keystore，换签名后无法覆盖安装）
